# v0.4.0

v0.4.0 makes the way agni reads a board's names something a person can see and change. Every
pattern that decides what a net, a pin or a part is now lives in one lexicon, with a reason on every
role it assigns. `agni lexicon` and a viewer panel show that lexicon, explain one net, and dry-run a
convention before a project commits it. The release also adds an ODB++ reader and reads KiCad 6 and
7 files, which used to load as empty designs. It also drafts a pin map from the netlist, and fixes
how KiCad boards are placed and drawn. It is a minor release because five exported Go functions
moved onto the model, which `RELEASING.md` puts in a minor. Breaking lists them with what to change.
Everything in v0.3.15's notes holds.

## Breaking

- **Five `core/check` and `core/classify` functions moved or changed shape** (PR 1287, PR 1288), so
  that a rule reads the lexicon of the run it is in rather than the process's. Migration:
  - `check.NominalVoltageFromName(name)` is `m.NominalVoltage(name)` on the `check.Model`.
  - `check.RailMaxVoltage(n, name)` is `m.RailMaxVoltage(n)`.
  - `check.ExpectedDiffNegative(name)` is `m.DiffNegative(name)`.
  - `check.NoConnectMarked(n)` is `m.NoConnectMarked(n)`.
  - `classify.BuildValueVocab(units)` returns `(*ValueVocab, error)`, refusing a unit map it
    cannot read.
- **`classify.StampMPN` runs when a design is derived, not when it is parsed** (PR 1289). A host
  calling `formats.Loader.ParseDesign` alone gets no part numbers. `DeriveDesign` stamps them under
  the run's lexicon, so a project's own part-number keys apply. A host reading through
  `ReadDesign`, as every surface in this repo does, needs no change.
- **A KiCad input pin stays an input, whatever its name** (PR 1258). On KiCad, gEDA and Telesis the
  supply-name promotion to `power_in` now fills only pins typed unspecified, so a sense pin named
  `VIN` or `VBUS` is no longer judged by the supply rules. EDIF, IPC-2581 and xschem are promoted as
  before. On the four public KiCad boards in the oracle corpus this removed 28 findings KiCad's ERC
  does not report.

## Added

- **One lexicon for every name** (PR 1269, PR 1287, PR 1288, PR 1289). The I2C bus names, the
  exposed-pad names, the TVS part-number families, the diode, feedback and switching pin names, the
  no-connect and differential-pair spellings, a name's voltage, bare value units, class exclusions,
  and the attribute keys for part number, value and do-not-populate are all lexicon vocabularies now.
  Each takes the project override the others do, plus an `exclude` list. A net is also a rail when a
  later token of its name is a supply word and it feeds a fitted part's supply pin, which reads
  `LPC_VCC` as the rail it is. Every net role carries the reason it was assigned.
- **`agni lexicon <design>`** (PR 1273) lists the effective lexicon with each entry's source
  (built-in, server, project, design or request). `--net` explains one net's roles and every pattern
  its name matches. `--try <conventions.yaml>` reads the design again under a candidate and tables
  the nets whose roles change and the findings that appear or disappear. `--format yaml` writes the
  effective lexicon as a conventions file. It runs over the new `LexiconService`, so `--remote` and
  any client ask the same questions.
- **A Lexicon panel in the viewer** (PR 1276), tabbed beside Rules, lists every vocabulary, edits a
  draft convention, tries it, saves it as YAML and applies it for the session. Net Properties shows
  why each role is there.
- **`--conventions` on `stats`, `diff` and `render`** (PR 1279), and the viewer's Compare reads both
  sides under the convention in the vocabulary bar.
- **The KiCad reader keeps every symbol property** (PR 1289), so a schematic's DNP field and part
  number reach the engine. On the public boards HackRF One now reads 325 part numbers and 34 unfitted
  parts where it read none. The extra properties sit on the part's section, so they never change how
  a part is classified.
- **An ODB++ reader** (PR 1262, PR 1271). `readers/odb` reads a job folder, `.tgz` or `.zip` into
  both a netlist and a board, and every surface opens one, the browser's drop included. A layout is
  compared with its schematic by `agni diff schematic.edn job/`. Jobs written by Altium Designer
  read too. `examples/odb-verification` and `make exercise-odb` walk it on the tutorial gateway, and
  `make odb-oracle` holds each sample board's ODB++ export to its `.kicad_pcb`.
- **KiCad 6 and 7 files read** (PR 1235). Before, a KiCad 6 schematic read as an empty design and a
  KiCad 6 or 7 board read with no components, with no error. HackRF One, Glasgow and Cynthion now
  read with KiCad's own net counts, and the oracle corpus cross-checks them.
- **`agni pinmap <design> --device J1`** (PR 1259) drafts a pin map for one device. It lists every
  pin with its net and walks each signal through series parts to the IC or connector pin it reaches.
  The output is an intent file that `agni check --intent-path` reads.

## Changed

- **A multi-hop pull-up pass states its whole route** (PR 1270), spelled as `agni trace` spells
  one, so `check --rule i2c-pull-up --verdicts` is a per-net sign-off table.
- **A query link brings its answer forward** (PR 1251, PR 1277). Following one brings the Query
  panel to the front and locates a one-row answer. The MCP `query` and `query_set` replies now label
  their links as a re-run in the Query panel.
- **A strap band that could not be compared is inconclusive** (PR 1283) rather than a pass, naming
  the resistor whose value was missing or unreadable.
- **A pin the schematic marks no-connect is left unjudged** (PR 1290) by `i2c-pull-up`,
  `power-input-not-driven` and `decoupling-present`, when it is the net's only pin.

## Fixed

- **KiCad board placement** (PR 1271, PR 1274). A footprint at 90 or 270 degrees drew pad 1 where
  pad 2 is, back-side parts were mirrored twice, and text was drawn at the wrong angle (2882 of 4920
  footprint labels on the sample boards). Arc tracks are read, and a thin one fails `track-width`
  (PR 1280). Jetson alone has 2,316 that the copper rules never saw. A slotted hole reads as its
  width rather than 0.
- **Four false-positive shapes on HackRF One and Cynthion** (PR 1278). A clamp array's supply pin
  is no longer a load. A connector's own supply pin no longer makes a decoupling subject. `spi_nor`
  reads the COPI/CIPO spellings. A regulator fed from a net its loads do not drive counts as a board
  source, and a new `net_tie` class lets the series walk cross a shorted header.
- **A project's convention reaches the board-source walk** (PR 1286), which read the process-level
  vocabulary, so `--conventions` and `--try` could not change it.
- **The `PWR` rail prefix must end its token** (PR 1269), so `PWRCTL_POL` is no longer a power net.
  `bulk-cap` judges nets with a power symbol, a power flag, or a global label on a rail, rather than
  every global label.
