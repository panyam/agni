# v0.3.5

v0.3.5 reads the values of parts whose libraries name them by value, says why when a check run fails
in the viewer, and gives a diff its own viewer link. It is cut as a patch at the maintainer's call,
although one change removes an exported Go function and another renames a field in the MCP `diff`
tool's structured answer, which `RELEASING.md` would put in a minor release. Both are listed under
Breaking with what to change. Everything in v0.3.4's notes holds.

## Added

- **A viewer link for a diff** (PR 1130). The older revision's view with `?against=<mount>/<path>`
  opens it with Compare already started against the newer one, as picking it in the Compare picker
  does, on a server or on the static demo. `agni diff <old> <new> --server <url>` prints it to stderr
  after the diff (`look at it:`), withholding it under the same rules as any link, and the MCP `diff`
  tool returns it as its one link. A diff run with `--rename-approx`, or the MCP tool's
  `rename_approx`, adds `rename_approx=1`, and the comparison's tables open with near-renames paired.
- **A failed check run says so** (PR 1129). A run that fails, from a lost snapshot, a worker that died
  or a budget the server enforced, shows the engine's message in the Checks panel with the selected
  rules it left unrun, where the panel used to read as if Run was never pressed. A rule catalog that
  fails to load says so in the Checks and Rules panels instead of "No rules." A cancelled run still
  reads as cancelled.

## Fixed

- **A value written as a library part name is read** (PR 1128). A library that names its parts by
  value writes that name as the Value, `R_10k_0402` or `C_4u7_25V_0402`, which parsed to nothing, so
  every passive on the Jetson baseboard (403 resistors, 377 capacitors, 8 inductors) had no value. The
  value pass now reads one token from such a name: one with an SI prefix or a unit, in the part's own
  unit, so a package size (`0402`) never reads as ohms and a rating (`25V`, `22.4A`) never reads as
  the value. A name holding two different values reads as none. A strap band that was passing
  unchecked now judges its resistor: on Jetson, a band declared on `/DCDC/12V_MODE1` passed with R13
  at 499 kOhm, five times its maximum, and now fails. The shipped catalog's verdicts on Jetson and the
  seed triage records are otherwise unchanged.
- **`agni diff --server` says a note about the server once** (PR 1130), where an unreachable server's
  "links are unverified" note printed once per revision.
- **The guide no longer says the static demo cannot open a comparison** (PR 1130); it opens one from
  its Compare picker or a diff link.

## Breaking

- **`report.DesignURL` is removed** (PR 1130). The MCP `diff` tool was its only caller, and it now
  links the comparison through `report.DiffURL(meta, bmeta, renameApprox)`. Migration: a caller
  linking one design builds `meta.URLBase + "/designs/" + meta.MountPath + "/view"`, or links a
  comparison with `DiffURL`.
- **The MCP `diff` tool's structured answer carries `link`, not `links`** (PR 1130), the key every
  other tool's answer uses for its one link, and its text ends in one `open in the viewer:` line
  instead of one per revision. Migration: an MCP client reading `links[0]` and `links[1]` reads
  `link`, which opens the comparison.
