# The power checklist, one file per item

`project.yaml` names this folder as the `power` checklist's `items_dir`. Each `.md` file is one item.
Its frontmatter carries the item's `id`, `title` and binding, and its body holds free notes the review
ignores. A folder such as `01-power` names the area, without its ordering number, and an `area:` field
in the frontmatter overrides it. Items run in the order of their ids. This README is not an item.
