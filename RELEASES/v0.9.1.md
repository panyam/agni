# v0.9.1

v0.9.0's tag built every artifact except the `agnids` image. In that image agnids exited at start, since it tried to create `/var/lib/agni/files` as a user that can't write there. So `ghcr.io/panyam/agnids:v0.9.0` never published, and the v0.9.0 GitHub Release was not published either. v0.9.1 fixes that and bumps oneauth. It is a patch over v0.9.0, with no change to an existing Go API. Coming from v0.8.x, read [v0.9.0's notes](v0.9.0.md) first, since its Breaking section applies.

## Fixed

- **agnids starts over an uploads folder it can't create** (PR 1768, issue 1767). agnids only reads `--uploads`, so it no longer creates the folder. It finds no uploaded files until `agni serve` makes the folder, then reads them, as it already did for the records under `--store`. The agnids image starts again, and `hack/image_smoke.sh agnids` passes.

## Changed

- **oneauth v0.3.9** (PR 1769). Its FS stores check the key inside a file before they read, write or delete it, so `agni token` refuses a token id whose file holds another token. Its FS stores also write on Windows.
