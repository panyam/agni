# v0.7.0

v0.7.0 carries mission 1586's viewer work, so a board can be probed from its schematic without managing the viewer. It also reads a design packed in any common archive, ships Windows builds, and adds `make try` for checking a viewer change by hand. It is a minor release, since it removes three exported Go functions that PR 1610 replaced. The Breaking section names each one and its replacement.

## Breaking

Archives moved out of the ODB++ reader into `internal/archivefs`, which reads every common kind as the folder it was made from (PR 1610, issue 1591). Three exported functions went with them.

- **`fshost.ExpandZips` is now `fshost.ExpandArchives`.** It takes and returns the same types, and it expands every archive kind, not only a zip. Migration: rename the call.
- **`odb.FromArchive` is removed.** It opened an archive's bytes as the job's file system. Migration: name the archive to `formats.Loader`, which reads it as a folder, or expand the folder holding it with `fshost.ExpandArchives` and call `odb.FindRoot` on the archive's directory.
- **`odb.IsArchiveJob` is removed.** Migration: `formats.IsODBArchive(b)` answers the same question for an archive's bytes.

`make demo-video` is also gone. `make try JOURNEY=<name> HEADED=0` records the same 1080p video (PR 1622).

## Added

- **The board view follows a selection to its side and its copper** (PR 1596, issue 1587). A click on a back-side part turns the board over to its back, and a click on a net turns on the inner layers its copper runs on. A **Follow side** box turns it off.
- **Step back and forward through what was selected, and through the sheets that draw it** (PR 1599, issues 1588 and 1589). **← Back** and **Forward →**, or `[` and `]`, select an earlier or later selection again. **‹** and **›**, or `,` and `.`, open the previous and next sheet that draws the selection, and the bar reads its place, such as "2 of 4".
- **Each board's layer stack** (PR 1602, issue 1592). `BoardGeometry` gains a `Stackup`, top to bottom, with each layer's thickness, material, εr and loss tangent where the file gives them, and the board's total thickness. `agni stackup <board>` prints it.
- **How well a schematic and its board agree** (PR 1605, issue 1590). The viewer counts the parts both views place and lists the rest, using the revision diff's matcher. A net the board names differently cross-probes to its schematic name.
- **Layer thickness in the board view** (PR 1606, issue 1603). Each layer row states its thickness, and a Stack table lists the whole board, dielectrics included. Its last line compares the layers with the thickness the file states.
- **An exploded view of the layer stack** (PR 1608, issue 1593). **Stack** draws the layers apart in WebGL, spaced by their thickness, with each via as a barrel between the layers it joins. A slider spreads the stack, and a click on an inner layer's track picks its net.
- **Archives read as the folders they were made from** (PR 1610, issue 1591). A zip, a tar, a 7z, or a tar in gzip, bzip2, xz or zstd opens as a folder in the CLI, `agni serve` and the browser engine. The bytes choose the decoder. Every kind is held to 100,000 files, 512 MiB a file and 1 GiB in all. An encrypted archive says so. Naming an archive that holds one design reads it, a zipped KiCad project as well as an ODB++ job.
- **Windows builds** (PR 1623, issue 1595). Each release carries `agni_<tag>_windows_amd64.zip` and `agni_<tag>_windows_arm64.zip`, each holding `agni.exe`. A CI job runs every Go test on Windows and serves a built `agni.exe` on a drive-letter mount to a headless browser. The install page has Windows steps.
- **`make try JOURNEY=<name>`** (PRs 1619, 1621 and 1622, issue 1600). It plays a demo journey in a visible browser at a pace a reader can follow, then hands the browser over. `UNTIL=<step>` stops before a step, `STEP=1` waits for a Next button, and `RECORD=1` records the window, the reviewer's own clicks included, as an mp4. `HEADED=0` records the journey headless at 1080p for the docsite.

## Changed

- **`mounts.SafeResolve` refuses a rooted path such as `\srv` or `C:srv`** (PR 1623). On Windows `filepath.IsAbs` calls those relative. `agni.yaml` keeps a rooted path as written rather than joining it under the file's folder. On macOS and Linux both behave as before.

## Fixed

- **`find-a-part`'s last step on a small board view** (PR 1620). It zoomed in about the view's middle, which pushed the test point back out, so the journey broke at step 5 on Jetson's whole board in a laptop's window.
