# v0.6.4

v0.6.4 carries one PR. It moves jaala from v0.1.99 to v0.1.101. The release is a patch, with no Go
API change.

## Changed

- **jaala v0.1.101** (PR 1471). A query module may now state a fact, a clause of one ground atom.
  Constants in a rule's head no longer close a column's values. So a query naming a value that no
  rule writes answers nothing, where it used to fail with "holds one of". A declared `{…}` domain
  still closes the column. Lint warns when two atoms of one relation differ only by a variable that
  nothing compares. The natural-language frontend's paths action no longer panics when every join
  fails, and its refusals name their kind.

## Fixed

- `make odb-oracle` passes again (PR 1471). PR 1407 added each pad's angle to how the ODB++ oracle
  spells a pad, and the baseline still spelled four known differences without it.
