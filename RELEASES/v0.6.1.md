# v0.6.1

v0.6.1 gathers 28 PRs. A walk outwards from a part now asks where a line goes next, to a pin, to
its pull-up or to the rail, and the viewer walks hop by hop from Properties. The WebGL canvas picks,
box-selects and lights findings as the SVG view does, and its button is back. A board view beside
the canvas keeps its own layer list and answers a click in about a second on Jetson. Allegro boards
read their pin names, constraint sets and declared differential pairs, and Capture net names match
the netlist Capture hands Allegro. The release is a patch by choice, though it adds rpcs and fields
as a minor would. Four Go API changes can break code that implements or passes around agni's types,
and "Go API" below lists them.

## Added

- **A walk asks a goal question** (PR 1422, PR 1427). `WalkDesignRequest.goal` asks from a net the
  walk reached (`at`) for a route to a pin, to the line's pull-up, or to the nearest rail. Each
  route runs from the walk's start along the walk to `at`, then through trace's series walk or the
  pull-up rule's own search. The answer keeps trace's three outcomes, routed, no route within the
  radius, and unresolved. `agni walk --goal pin|pull-up|rail --at <net>` asks it, and the viewer
  zooms the canvas to the route and opens the sheet that draws its last net.
- **A walk in the viewer** (PR 1420). A selected part or pin gets a walk row in Properties, with
  one button per walk kind from `ListWalkKinds`. The Trace tab groups the walk's nets by hop, says
  where and why it stopped, and offers Wider, Narrower, and Cross for each part it left uncrossed.
  The canvas lights each hop in its own shade.
- **A walk follows a translator's channel** (PR 1415). The lexicon's `pin.through_pair` pairs pin
  names that carry one signal across a part (`A{n}`/`B{n}`, `{n}A`/`{n}Y`, `SDA1`/`SDA2`), and
  `Model.ThroughPartner` answers a pin's partner. A walk crossing a paired part goes on through the
  partner alone. `make exercise-walk` is mission 1337's exercise.
- **Sheet views through the viewer page API** (PR 1424). `ViewerPageService` gains `OpenSheetView`
  and `CloseSheetView`, `ShowSheet` takes a `view`, and `GetLocation` lists the open views. A pick
  and a reader's question name the view they came from, `canvas` or `sheetview-<n>`, and the room
  bridge declares eight page tools.
- **Picking on the WebGL canvas** (PR 1448, PR 1451). A click picks what SVG would pick, through a
  grid index over the packed sheet's keys and SVG's nine probes. Shift-drag selects an area,
  Shift-click adds to it, and Properties reads a sheet's parts and nets from whichever renderer drew
  it. The WebGL button is offered again, and SVG stays the default (PR 1455, DECISIONS.md).
- **A board view's own layer list** (PR 1453). A board view beside the canvas opens the Sheets
  panel's layer list from a Layers button, over a hidden set of its own, so hiding In1.Cu there
  leaves the canvas drawing it. Each inner copper layer takes its own colour from
  `Style.CopperInners`, in both themes, and the SVG board, the WebGL groups and the swatches agree.
- **Allegro pin names and constraint sets** (PR 1431, PR 1433). Each component definition becomes a
  part type with Allegro's pin names, so `pin.name`, `trace --from U4.<name>` and the IO-map rules
  read them. Each physical constraint set becomes a `netclass` constraint, so
  `netclass-track-width` runs, and `track-width` holds the board to its narrowest set.
- **Declared differential pairs and match groups** (PR 1438, PR 1450). `ir.Design.net_groups`
  carries what an Allegro board declares, 17.2 and 16.6 alike, with a strobe pair read inside its
  byte lane. `diff-pair-naming` passes a declared pair on the declaration, and
  `net.group(group, kind, net)` queries them.
- **Pours in `copper-clearance`** (PR 1417). A track measures against a pour's outline and holes, a
  pour against another net's pour, and copper wholly inside another net's pour fails as a short.
- **Pads at their offset and by their outline** (PR 1421). `PadShape.offset` and `PadShape.outline`
  place a padstack land off its pin and draw a custom pad. Allegro and IPC-2581 read them, and a
  KiCad 9 `(padstack ...)` block reads per layer.
- **ODB++ and IPC-2581 part types** (PR 1445). Each package becomes the part type of the parts
  placed from it, with its pins, leaving out mechanical pins. A fiducial no longer fails
  `unconnected-component`.
- **Sample boards fetched from their publishers** (PR 1450). The `remote-boards` artifact lists
  boards whose repos state no licence, and `hack/fetch_remote.sh` downloads each into a cache once.
  agni-samples is pinned at v0.1.15 (PR 1447, PR 1450).
- **`make exercise-webgl`** (PR 1439, PR 1441). It walks the WebGL mission's steps on Jetson in SVG
  and then WebGL, with highlights lit, and `VIDEO=<dir>` records the walk.
- **The cross-probe walk on Clay R6** (PR 1418), an OrCAD design on its Allegro board, in the gate
  beside the Jetson cut.

## Changed

- **Findings light the board and an EDIF schematic in WebGL** (PR 1444, PR 1457). The board's nets,
  and the wires of a schematic that names nets without ids, are keyed with the design's net ids
  through a resolver built from the netlist. A name two nets share gets no id, and a finding's
  spec carries the name for it.
- **Capture net names match `pstxnet.dat`** (PR 1429). An unnamed net is numbered after the lowest
  wire id on it, and the shallowest name wins. A dropped Capture folder proposes one design, a
  pin Capture flags not connected draws a cross, and the hierarchy strip offers Read every block
  only when it would read more (`GetDesignResponse.flatten_reads_more`).
- **The page stops blocking once a sheet is drawn** (PR 1456). The rest of the load shows in a pill
  that takes no input, and a newer open supersedes one still loading.
- **A turned board view stays fast** (PR 1452). Its turn layer gets its own compositor layer, which
  took a frame on Jetson from about 700 ms to 17 ms and a board click from 11.5 s to 1.2 s. The
  board view's bar wraps inside its panel, and the canvas readout, mode bar and notes share one
  column.
- **A picked pin frames its part's unit** (PR 1426), so a test point at the end of a long leg sits
  on the canvas.
- **A board read's note says where the board is read** (PR 1445), as a declaration rather than a
  claim that it was read.
- **Relay tokens come from massrelay's signer** (PR 1460). massrelay moves to v0.3.7 and oneauth to
  v0.3.2.
- **`make exercise-cross-probe` builds the wasm** before it walks.

## Fixed

- Lighting a large net in WebGL no longer overflows the call stack (PR 1441).
- An Allegro supply-pin name such as `VIN1A_D10` or `VBUS_DET` no longer reads as a supply input,
  and a board file's untyped pins no longer promote to power inputs (PR 1431).
- The IPC-2581 and ODB++X reads of an Allegro board agree with the `.brd`, track for track (PR 1438).

## Security

- Eight Dependabot alerts cleared (PR 1460). `solid-js` moves to 1.9.18, which brings `seroval`
  1.6.12 past six advisories, one of them critical. `vitest` moves to 5.0.5, which brings
  `@vitest/mocker` past two.

## Go API

gorelease against v0.6.0 lists these as incompatible. A caller that only calls them is unaffected.

- `core/model.Model` gains `DeclaredPair`, `NetGroups` and `ThroughPartner` (PR 1415, PR 1438). A
  type outside agni that implements `Model` adds the three methods.
- `render.HighlightBoardSVG` takes a variadic `...render.Option` (PR 1444). A call compiles
  unchanged, and a function value of the old type needs the new signature.
- The generated `viewerconnect.ViewerPageServiceClient` and `ViewerPageServiceHandler` interfaces
  gain `OpenSheetView` and `CloseSheetView` (PR 1424). A handler that embeds
  `UnimplementedViewerPageServiceHandler` compiles unchanged.
