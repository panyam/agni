# v0.6.20

v0.6.20 opens Jetson's board cold in the browser engine in about 1.3 s, down from 2.3 s, so every step of the board-open exercise now meets its target. It is a patch. No API changes.

## Changed

- **`agni serve` builds a design's browser-engine seed as soon as a request names it** (PR 1585, issue 1572). The seed is the design's parsed board, which a first browser-engine visit restores rather than parsing the board itself. The server used to build it only when a page asked for it, and Jetson's took about 860 ms. A request that lists or reads the design now starts the build in the background, and the page's request waits on that build rather than starting a second.
- **A seeded browser-engine load that opens on the board reads nothing more before the viewer opens** (PR 1585). It used to read the board again with `Ingest`, about 400 ms on Jetson, though the seed had restored it. The viewer builds the check model after the board draws, as it already did. A load that opens on a schematic, or one with no seed, reads as before.

In `make exercise-board-open RUNS=5` on an M5 Pro, wasm cold went from 2.3 s to 1.3 s. The other four steps are unchanged.
