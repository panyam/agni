# v0.6.19

v0.6.19 draws a WebGL frame in runs of one group rather than with a call per primitive. Jetson's board now takes 1,239 draw calls at most rather than 36,636, with the same pixels. It also lets `make serve` in a checkout serve the viewer it just built, ahead of a `web_dir` in `agni.yaml`. It is a patch. No API changes.

## Changed

- **A WebGL frame draws in runs of one group** (PR 1584, part of issue 1484). A run is a set of primitives in one group, which share a colour. A primitive joins its group's latest run unless something drawn since overlaps it, so paint order holds wherever shapes touch. Each run splits by a coarse grid into chunks the view culls, and each chunk draws its wide lines, lines, triangles and points as one indexed call each. On an M5 Pro, Jetson's board drew in 1.3 ms at p95 and now draws in 0.2 ms. A sheet's first frame still draws one primitive at a time, and the runs are laid out after it, so the board's first draw is no slower. A comparison against the previous release shows no pixel changed on the board both ways up, on a schematic sheet or with a walk lit.
- **A checkout's own viewer wins over a configured `web_dir`** (PR 1582). `make serve` builds `./web` and runs with no `--web-dir`, and a `web_dir` in `agni.yaml` that named a tree no longer there stopped it serving. The order is now `--web-dir`, a checkout's `./web`, `agni.yaml`'s `web_dir`, `AGNI_WEB_DIR`, then the default. A half-built `./web` is still an error.
