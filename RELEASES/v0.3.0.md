# v0.3.0

A design is named by a snapshot of it, ingested once, and every question names that snapshot. The
browser demo reads a design on a Load page before the viewer opens it, checks a selected net on its
own, and can cancel a run. No rule credits a do-not-populate part, and every seed finding of a rule
KiCad mirrors says whether KiCad's own ERC and DRC agree. agni moves to jaala v0.1.84.

It is a minor release because the wire changed under every analysis rpc.

## Breaking

- **Every analysis request names a `snapshot` and nothing else about the design** (PR 1068). The
  `uri`, `board_uri`, `as_named` and `overlay` fields are gone from the 19 analysis requests, and
  `DiffDesigns` takes `a_snapshot` and `b_snapshot`. Call `SnapshotService.Ingest` with the design's
  definition first, then ask with the `snapshots/{id}` it returns. A question about a snapshot whose
  files changed fails with FAILED_PRECONDITION, and one the host no longer holds with NOT_FOUND, both
  with a `SnapshotUnavailable` detail. The CLI and the Python client (`ingest()`) do this for you.
- **`CheckService.LoadDesign` is removed** (PR 1068). It was added in PR 1065 and never released.
  Reading a design's board ahead of its first question is an `Ingest` with `read_board`.
- **`list(?x)` answers a list value in its JSON text** (PR 1083, jaala v0.1.79). Where a cell read
  `R3 R4` it reads `["R3","R4"]`, and over nothing it is `[]` rather than empty. A script that split a
  list cell on spaces parses it as JSON instead.

## Added

- **`SnapshotService` holds a design's snapshots** (PR 1068) through `Ingest`, `GetSnapshot`,
  `ListSnapshots`, `UpdateSnapshot` and `DeleteSnapshot`. Two ingests of one design are two snapshots sharing one cache beneath them.
- **A snapshot can carry its design's files** (PR 1069), so `--remote` needs no shared filesystem.
  An ingest naming contents the server lacks fails with `BlobsMissing`, the client sends them with
  `UploadBlobs`, and every locator reads as it would on the client. `agni serve --upload-max-bytes`
  bounds what is kept (1 GB by default).
- **`CheckDesign` answers for the nets, parts and pins it is asked about** (PR 1071), and `agni
  check --subject net:SDA0` sends them. A rule a scope leaves out is listed in `skipped` with
  `design_wide` set (PR 1076).
- **Each design has a Load page beside its viewer** (PR 1074, agni issue 1072), at
  `/designs/<mount>/<path>/load`. It reads the drawing, the netlist and the board into the browser
  engine's store and then opens the viewer, which opens only a design the page recorded. Dropped files
  are kept in IndexedDB and survive a reload.
- **Properties checks a selected net, part or pin on its own** (PR 1076, agni issue 897), and a
  verdict link carries its subjects (`subject=net:GND`), so following one asks that rule about them
  alone.
- **Run checks and Run review can be cancelled from their buttons** (PR 1077, agni issue 918). A
  cancelled run leaves the rules it had not answered pending and says so.
- **`component.dnp(ref_des)` names each part marked do-not-populate** (PR 1083), which a query negates
  to leave an unfitted part out.
- **Queries gain jaala's new forms** (PRs 1064, 1083). They are `optional { }` (a left outer join,
  carried on the wire as `DatalogLiteral.opt`), facts as terms (`edge(?a, ?b) as ?r`, `DatalogAtom.fact`), the
  `avg` aggregate, `coalesce`, `list.*`, the `str.*` builders, and `graph.closure` and `graph.paths`
  for a bounded walk over a step relation a query names.
- **`hack/kicad_oracle.sh`** writes KiCad's ERC and DRC over each public-demo seed beside its triage
  record, and `TestSeedTriageAgainstKiCad` holds the records to them (PR 1083, agni issue 967).

## Changed

- **No rule credits a do-not-populate part** (PR 1083, agni issue 961). The reach walk crosses no
  unfitted part, so the TVS, ICESD, power-path, bias and power-pin walks, `net.reaches` and
  `net.route` all inherit it. `decoupling-present`, `bulk-cap` and `crystal-load-caps` count no
  unfitted capacitor, and the ESD profile no unfitted clamp. A test point keeps its credit, since a
  pad-only test point is marked DNP because nothing is placed on it. A net with no fitted part is not
  considered by `bulk-cap` and `esd-protection`, and `decoupling-present` asks for a fitted supply pin.
- **A part placed from a cell its EDIF file never declares has the pins its connections name** (PR
  1078, agni issue 975), so `pin.net` answers what `net.pin_count` counts.
- **A scoped check walks only what it was asked about** (PR 1078). `copper-clearance` measures the
  asked nets' copper against its neighbours, the spec rules skip uncovered elements, and the profile
  rules test the asked nets against their signals first. All rules asked about one I2C net on Jetson
  went from 66 ms to 9 ms.
- **The browser's serve worker is not given the board's file** until a question reads it (PR 1080,
  agni issue 992), 85 MB of Jetson's 92 MB.
- **A design's parse is kept apart from the design derived from it** (PR 1066), so another project's
  conventions over the same files parse nothing again.
- **The board is read in a worker that ends once it answers** (PR 1065), so its parse does not stay
  in the checking worker's memory for the visit.
- **A rule is listed available exactly when a run of the design runs it** (PR 1079, agni issue
  950), and the Checks panel lists the rules this design cannot run.
- **The static demo's Compare picker lists its designs** (PR 1081, agni issue 978).
- **The circuit walks charge their own work to a query's budget** (PR 1064), so a budgeted all-pairs
  walk stops partway through rather than after it finishes.
- **jaala v0.1.84** (PRs 1064, 1083).

## Seed triage

Jetson's `unspecified-pin-with-driver` on +1V8 is now a false positive (#1082): U59's OE is declared
`tri_state`, which the KiCad reader keeps as UNSPECIFIED. KiCad agrees with Jetson's `single-pin-net`,
the Feather's four `power-input-not-driven` nets and the gateway's `track-width`, and reports 357
clearance violations on Jetson from its `.kicad_dru` rules, which agni does not read yet (#142).
