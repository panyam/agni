# v0.3.3

v0.3.3 moves agni to jaala v0.1.85 and brings the README up to what has shipped. Nothing in the
engine, the viewer or the wire changes beyond what the new jaala allows a query to say, so it is a
patch release. Everything in v0.3.2's notes holds.

## Changed

- **jaala v0.1.85** (PR 1111), in every module that names it. Two things a query can now say:
  - A comparison against a constant binds its variable, so `?k = "tag"` works where `?k` was
    unbound.
  - A goal column can be a constant (`=> ?x, "tag"`).

  Answers are unchanged. On the Jetson seed `agni check` printed byte-identical output on v0.1.84
  and v0.1.85, and its rules took 176 ms against 179 ms on the same machine.

## Docs

- **The README names what shipped since it was written** (PR 1111): the public demo, which runs the
  engine in the browser with nothing installed, the compose bundle each release attaches, `--remote`
  and the Python client, `agni review` and `agni trace`, reading a hierarchical EDIF whole,
  `SECURITY.md`, and what `make testall` runs.
