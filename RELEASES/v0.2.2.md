# v0.2.2

Five weeks of work since v0.2.1, about 170 pull requests. The engine now runs in the browser, so a
board can be analysed on a static page with nothing installed. The datasheet tooling is its own
module and image. Projects carry their own derived relations and query sets. The viewer has a
Properties panel, query tabs, and saves every report the CLI writes.

The version number understates this. Several changes below alter output that a script or a CI gate
may read, which would ordinarily be a minor release. It is tagged as a patch deliberately, as v0.2.1
was, because there are no external consumers yet. If you parse agni's output or gate on it, read
**Changed** first.

## Changed

- **`agni review --format json` prints the `Review` the `CreateReview` rpc returns** (PR 814), and
  several designs print a `ListReviewsResponse`. Field names follow protojson's lowerCamelCase. Items
  keep `id`, `title`, `outcome` and `findings`. The counts a gate reads are `summary` on the `Review`.
  The old `per_design`, `not_automated` and outcome matrix are gone.
- **A length is published in metres and shown in millimetres** (PRs 1036, 1038). The engine folds a
  query literal to its SI base, so a threshold over a board length writes its unit:
  `board.track_width(?n, ?w), ?w < 0.2mm`. A bare `0.2` now means 0.2 m and matches nearly every
  net. Every answer, report and capture still shows millimetres.
- **A project's conventions and checklists are sections of `project.yaml`, and a design's intent is a
  section of `design.yaml`** (PRs 826, 830). A `conventions.yaml`, `review.yaml` or `intent.yaml` left
  in the old place is a load error naming where its content goes.
- **A value reaches a query as a binding, never as spliced text** (PR 805): `--bind name=value`, a
  set's `bind:`, and the viewer's click and search presets.
- **`agni query --set` takes a project set's name as well as a file** (PR 1034). A value ending
  `.yaml` or `.yml` is a file, and any other value is a name the design's project must keep in
  `queries/`. A misspelled key inside a set's query is now refused with its line.
- **The Python client's `tabulate` returns the engine's tables** (PR 867), and the client-side row
  builders (`verdict_sheets`, `natural_key`, `set_sheets` and others) are removed.
- **The datasheet workbench is `agnids`, its own binary, module and image** (PRs 776 to 787). `agni
  serve` no longer serves it, and `agni serve --datasheets-url` links to one. Workbench drafts live in
  the corpus store, keyed by part number (PR 801).
- **In the viewer, a click on the drawing selects** and describes the selection in Properties, which
  replaces Details, rather than writing a query (PR 1031). **Run checks lights nothing until a finding
  is clicked** (PR 1040); Highlight › Show every finding brings back the run-wide view.

## Added

- **The engine in the browser** (PRs 870 to 948). `agni serve --engine wasm`, a page's `?engine=`, or
  `agni site` for a static demo, published with the docs at `/agni/demo/`. Dropped files and folders
  open as designs (`ProposeDesigns`), a parsed design is kept in the browser's cache, and a design
  past `--wasm-max-bytes` goes to the server.
- **Projects**: a design's revisions, each read with its own board (PR 879); a project's own derived
  relations in `lib/` (PR 780) and query sets in `queries/` (PR 1034); `agni checklists` and
  `ListChecklists` (PR 876); connector exposure declared in a design's intent (PR 834).
- **Queries**: named query sets over one read (`--set`, `RunQueries`, PR 746); a library of derived
  relations with a drill-down catalog (`agni query --relations`, PR 775); libraries sent with a
  request (PR 789); `--remote` to send a command to a running server (PR 1025); a work budget for
  served queries (PR 800); an aggregate over nothing answering one row (PR 732).
- **Tables**: `TableService.Tabulate` and `Encode`, so every csv and workbook carries the engine's
  rows (PRs 867, 871, 979); the Python client's `tables_to_xlsx`.
- **The viewer**: query tabs with several served questions per selection (PR 1033); a project's query
  sets opened as tabs (PR 1034); Save report, Save JSON and Save CSV for a check run, rendered by the
  engine the CLI uses (PRs 955, 979); Save report for a checklist run, through
  `ReviewService.RenderReviewReport` (PR 1039); a Tables panel (PR 979).
- **A typed Python client** over the CLI and the Connect API (PR 738), speaking binary protobuf by
  default (PR 917).
- **Readers**: EDIF keywords in any case, so an Altium netlist reads (PR 944); KiCad group buses, a
  placed symbol's `lib_name`, external nets beside a project, and KiCad's own net names (PRs 954,
  1012, 1017, 1024); a read's unexpanded EDIF hierarchy reported on every surface (PR 719).
- **Checks**: copper checked against the minimums a board declares (PR 947); device classes carry
  the evidence that established them (PR 711); a thermistor class (PR 676); a seed triage that holds
  every finding on the public demo's boards to a verdict (PR 942).
- **Measurement**: `--timing` on check, query, trace and review, `Agni-Timing` headers, and per-stage
  memory (PRs 965, 986, 1001); `make wasm-bench` and `make wasm-layers` (PRs 881, 989).

## Fixed

- **Jetson's Run checks.** The ESD profile rules ran about ten times slower from jaala v0.1.57,
  because the planner walked the board once per TVS net. jaala v0.1.60 fixes it (panyam/jaala#304),
  and a work-budget test guards the shape (PR 1038). Jetson's Run checks in the local demo takes about
  5 s, against 10 s on jaala v0.1.53 and 28 s on v0.1.59.
- **Opening a design as a folder** answered the parts lookup and the layout report with an error
  (PR 1031).
- **A review scored in the browser** now reads the board its design declares (PR 704).
- **An inconclusive result** is no longer counted or coloured as a defect (PR 706).
- **A misspelled value in a query** is refused rather than answering no rows (PR 697).

## Dependencies

- jaala moved from the in-tree engine to `github.com/panyam/jaala`, now at v0.1.60 (PRs 740 to 1038).
- goapplib v0.7.6 and tsappkit v0.7.3 for the browser engine (PRs 958, 995).
