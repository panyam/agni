# v0.6.3

v0.6.3 gathers 3 PRs. A board with no drawn schematic now opens as the board alone. An ODB++ job, an
Altium or Allegro board, an IPC-2581 file or a lone `.kicad_pcb` lists the Board sheet and no grid
of its netlist, and every answer that says where something is drawn names the board. The viewer
picks its renderer with one WebGL checkbox in place of a three-button switch. jaala moves to v0.1.99
and mcpkit to v0.8.20. The release is a patch. It adds one exported method and changes no Go API.
With it, mission 1329 (pan, zoom and click Jetson's whole board in the browser without lag) is
closed, and SVG is still the default renderer.

## Changed

- **A board with no drawn schematic shows the board alone** (PR 1468). Before, the viewer opened such
  a design on agni's grid layout of its netlist, with the Board sheet second. Now GetDesign lists the
  Board sheet alone, with no layout to pick and no drawing note, and the viewer opens on the copper.
  Finding and verdict badges, LocateSubjects, query cells, traces, walks and review findings all name
  the board for such a design. A netlist with no board, such as a bare `.edn` or `.tel`, keeps its
  auto-layout. The visual diff and the CLI's `render` still lay a board-only design out.
  `service.Snap.BoardOnly` reports the case.
- **One WebGL checkbox picks the renderer** (PR 1470). The canvas bar had three buttons, WebGL, SVG
  and a Native button greyed out on most servers. It now has one WebGL checkbox, off for SVG, the
  default. Native gets a checkbox of its own only where the server can draw the design natively.
  Each sheet view's SVG/WebGL dropdown is the same checkbox. `?mode=` still picks a renderer from the
  address.
- **jaala v0.1.99 and mcpkit v0.8.20** (PR 1467). mcpkit moves in lock-step across its Go modules and
  `@panyam/mcpkit-rooms`. A query that projects a variable its goal never binds now says
  `projected ?x is not bound by the goal (nothing in it binds ?x)`.

## Fixed

- The design summary in Properties no longer shows an empty slot where a board-only design has no
  layout to name (PR 1468).
