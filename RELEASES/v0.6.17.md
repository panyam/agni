# v0.6.17

v0.6.17 makes a lit pin show in WebGL, the default renderer. In v0.6.16 a walk from a part began marking its start by its pins, and in WebGL those pins drew a pixel or two across, so the start barely showed. It is a patch. No API changes.

## Fixed

- **A lit pin on a schematic draws as a dot in WebGL, the size SVG draws it** (PR 1577, issue 1576). WebGL used to recolour the pin's own primitive, a single point. It now draws a filled disc of 0.0025 of the sheet's larger span, which matches the SVG dot. A walk's start pins and a walk from one pin both show this way. The board is unchanged, since a lit pad already shows at full size.
