# v0.11.7

A hierarchical board pushed to a server read only its top cell, even when its `design.yaml` set `flatten_hierarchy: true`. The server's verdicts on such a board were wrong, and the remote output gave no sign of it. v0.11.7 keeps `flatten_hierarchy` on every stored design. It also stops bootstrap from warning about companions on each start, and lets a checklist item file carry a team's own fields. It is a patch over v0.11.6. No exported Go API changes shape, and one output-only proto field is added.

## Fixed

- **A stored design keeps its `design.yaml`'s `flatten_hierarchy`** (PR 1891, issue 1887). Push, the viewer's upload, add and link now read `design.yaml` through one reader in `service/`. Before this, four partial parsers each read some keys, and none read this one. A bootstrap design entry also takes `flatten_hierarchy`, for a board linked with no `design.yaml`. `agni check --remote` and `agni review --remote` print the "only its top cell was read" note, as a local run does. `agni designs get` says "reads every hierarchical block" for a design that does.
- **Bootstrap counts linked companions as named** (PR 1892, issue 1890). A link of a declared entry follows the companions its `design.yaml` names. Each companion now records that entry in the new output-only `ArtifactSource.companion_of`. Bootstrap no longer reports these companions on each start, and `prune: true` keeps them. A companion linked by v0.11.5 or v0.11.6 gets the field on the next start, link or sync of its entry. No request can set the field.
- **A checklist item file may carry the team's own frontmatter fields** (PR 1894, issue 1888), such as `owner:` or `last_triaged:`. The review ignores them. A field that looks like a typo of a known one, such as `rul:`, still fails and names the field it meant. Items within an area run in the natural order of their ids, so `16` comes before `100`.

## Not in this release

A sync whose entry didn't move doesn't add `companion_of`, and `agni designs artifacts` doesn't print it (issue 1893). Operator source grants (issue 1889) wait on the agni half of the goapplib v0.7.38 bump.
