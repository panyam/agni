# v0.2.1

A patch release.  One user-visible fix, no API changes.

## Fixed

- **The viewer's default layout opened on Trace, hiding the query surface.**  `dock.ts` adds the
  Trace panel `within` the Query group so the two share a tab strip, and dockview makes the last
  panel added the active one.  The block that sets each stack's opening tab covered `details`,
  `checks`, `review` and `canvas` but never `query`, so the stack opened on Trace and contradicted
  that block's own rule, "Each stack opens on its first tab".  A reader loading the viewer got the
  Trace panel with no route in it, and had to find the Query tab to ask anything.

  Introduced in v0.2.0 by PR 611, which added the trace panel.  It shipped because
  `make browser-test` is not part of `make testall`: the query textarea was present in the DOM the
  whole time and only its visibility was wrong, which is precisely the class of defect jsdom cannot
  see and the browser suite exists to catch.  (PR 618)
