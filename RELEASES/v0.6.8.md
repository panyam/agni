# v0.6.8

v0.6.8 carries four PRs, all in the viewer. A board view beside the schematic stays on the board,
lights a walk, and parks while nobody uses it. A WebGL view draws only when what it shows changes. A
board opens with its fab layers hidden. A page opened with `?timing` logs how each burst of pan and
zoom drew. The release is a patch, with no Go API change. One packed record's spare bytes now carry
a line width.

## Added

- **A page opened with `?timing` logs an `agni draw <view>` line per burst of pan and zoom** (PR
  1485, issue 1331). The line names the renderer and the GPU, counts the scene, and times each frame
  after an input. A WebGL drawing adds its own draw time, its text-layer time and its draw calls. The
  report has no field for a net, part or sheet name, so a team can paste it into a public issue.
- **A walk lights beside the canvas** (PR 1488, issue 1480). A sheet view open beside a walk draws
  the walk's nets and parts as the canvas does, and a click on a part row in the Trace panel frames
  that part in the view and selects it in Properties.

## Changed

- **A board view whose board does not place the selected part says so and stays on the board** (PR
  1488, issue 1481). It used to follow the selection to a schematic sheet. The canvas does the same
  when it shows the board, and the note offers the sheets that do draw the part.
- **An idle SVG board view parks as an image** (PR 1488, issue 1482). A second after the pointer
  leaves, the view swaps its live svg for a picture of it, and a pointer or a reveal wakes it. On
  Jetson a pan of the schematic took about 690 ms of task time with the board view live and about
  270 ms with it parked, against about 240 ms with no board view open.
- **A WebGL view draws only when what it shows changes** (PR 1483, issue 1479). Every WebGL canvas
  used to redraw on every animation frame, so a board view redrew the whole board while the reader
  panned the schematic. A camera moved by a locked peer or the other side of a diff still draws.
- **A board opens with its fab layers hidden** (PR 1487, issue 1486), on the canvas and in a board
  view. The layer list and the All preset still show them. Storage keeps "show every layer" as `[]`,
  so a reader who turns fab back on keeps that choice across a reload.

## Fixed

- **WebGL draws a board's outlines at their width** (PR 1487). Zoomed in, courtyard and silkscreen
  outlines drew as 1 px hairlines while SVG and KiCad drew them at their width. A line now draws as
  triangles once its width spans a canvas pixel. It stays a line primitive, so a click still passes
  through it to the part.
- **A replaced sheet frees its GPU objects** (PR 1485). Each sheet switch left the old sheet's
  buffers, vertex arrays and program on the WebGL context.

## Wire

- A packed geometry record's two spare bytes become `stroke_um`, the width a line's source draws it
  at, in micrometres (PR 1487). Only a board's graphics set it, and 0 is a hairline. A reader that
  ignores it draws hairlines as before.
