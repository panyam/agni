# v0.6.2

v0.6.2 gathers 4 PRs, all for mission 1329, which asks for Jetson's whole board to pan, zoom and
click in the browser without lag. A board view beside the schematic can now draw in WebGL, and so
can the visual diff. A board's zones fill in WebGL as they do in SVG. Every drawn KiCad bus carries
its name, so a click on a bus selects it in either renderer. On an idle machine, a headed `make
exercise-webgl` measured a p95 frame of 20.9 ms in WebGL against 55.6 ms in SVG while panning
Jetson's board. SVG is still the default renderer. The release is a patch. It adds proto fields and
no Go API change.

## Added

- **Sheet views draw in WebGL** (PR 1461). The canvas and every sheet view draw through one
  `SheetSurface`. A view's bar picks SVG or WebGL, and a view opens in the canvas's renderer. A
  WebGL view turns as an SVG one does, and seen from below it draws and picks in the order SVG
  does. The page API's `OpenSheetView` takes a `renderer`, and each listed view names the renderer
  that drew it.
- **The visual diff draws in WebGL** (PR 1465). If the canvas draws in WebGL when a comparison
  opens, both sides draw in WebGL too. Each side lights its own changes with no highlight fetch.
  The union draws the new revision and shows the old revision's removed parts as ghosts. The two
  sides pan and zoom together in the design's own coordinates.
- **Zones fill in WebGL** (PR 1463). A zone draws as a translucent wash in its layer's copper
  colour, 18% as in SVG, so overlapping zones darken in both renderers.
  `PackedSheet.group_alphas` carries each group's opacity.
- **A click selects a KiCad bus** (PR 1462). Each drawn bus piece takes its name from the
  nearest bus label along the bus, the way the net solver names a branch, and an entry takes the
  name at its bus end. Before this, none of Jetson's 709 bus pieces had a name. A clicked group
  bus lists its members in Properties. `InputDiagnostics.group_buses` records group buses apart
  from `unmodeled_buses`, so `bus-not-modeled` never judges one.

## Changed

- SVG and WebGL size the title block by one formula (`titleBlockPx`). Before this, SVG drew it at
  36% of the frame and WebGL at 32% (PR 1463).
- `make exercise-webgl` builds Jetson's rev B. The walk compares two revisions in each renderer and
  times a board view beside the schematic. A headless Jetson walk gets an hour (PR 1462, PR 1465).

## Fixed

- A zone's wash in WebGL no longer turns white. The canvas now keeps its alpha at 1 while it blends, since the
  browser composites a canvas as premultiplied alpha (PR 1463).
- `render.WithStyle` keeps the switches an earlier option turned on, so `WithPinDots` before it
  still draws pin dots (PR 1463).
- `TableSetText` prints an errored section's query above its error, as markdown and html already
  did (PR 1463).
- `web/sample.pb`, the packed decoder's test fixture, matches the Go packer again, and a test holds
  the two together (PR 1463).
