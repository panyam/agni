# v0.6.5

v0.6.5 carries three PRs. KiCad text now draws where KiCad draws it, on the schematic and on the
board. Command-F opens Find by name, and a board view's flips show as toggles. The release is a
patch, with no Go API change. Three wire messages gain fields, and nothing is removed.

## Added

- **Command-F opens Find by name** (PR 1474). Command-F, or Ctrl-F off a Mac, brings the Query
  panel forward, selects Find by name and focuses its box. In another text field the browser
  keeps the key.
- **A board view's flips show as toggles** (PR 1474). Each flip button stays pressed while its flip
  is on. One flip is the bottom view, so the back copper draws nearest. The Bottom button is gone.
- **Board user text and logos draw** (PR 1475). A footprint's user text draws, with `${REFERENCE}`
  and `${VALUE}` filled in, so the fab layer shows each part's designator. A footprint whose
  reference is the `REF**` placeholder is still not a part, and its artwork now draws. That covers
  the OSHW logo and its legend.

## Fixed

- **A KiCad 6 or 7 schematic hides its hidden fields** (PR 1473). KiCad 6 and 7 write a hidden
  field as a bare `hide`, where KiCad 8 writes `(hide yes)`. The reader knew only the second form,
  so a sheet drew every hidden field over its symbols.
- **A board SVG is well-formed when a layer name holds `&`** (PR 1473). The layer name is now
  escaped in `data-layer`.
- **A multi-line board text draws one line per line** (PR 1475). The lines sit 1.61 heights apart
  and centre on the anchor, as KiCad draws them, in both renderers.
- **A board text starts and ends where KiCad's does** (PR 1475). KiCad draws board text in its own
  stroke font, which is wider than Arial. Each run now starts at KiCad's first stroke and is
  stretched to KiCad's length. On a real KiCad 7 board 662 of 663 runs agree with kicad-cli within
  0.1 mm at both ends. `TestBoardRunsAgainstKiCad` holds 5,611 runs across three boards to
  kicad-cli's measurements.
- **Hidden footprint user text stays hidden** (PR 1475). The board reader now reads KiCad 7's
  bare `hide` too.

## Wire

- `BoardText` gains `font` and `thickness`, and `PackedLabel` gains `width` (PR 1475). A client
  that ignores them draws as before.
