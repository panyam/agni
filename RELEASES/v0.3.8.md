# v0.3.8

v0.3.8 lets a reader select an area of a sheet and ask about everything in it. It also lets another
page, a saved report or an MCP answer move a viewer that is already open, and it shows how a query
row was derived. Every change is additive, and everything in v0.3.6's notes holds, including its
descriptor migration.

## Added

- **Select an area of a sheet** (PR 1171, #904). Shift-drag a rectangle over the drawing to select
  every part, pin and wire wholly inside it, and Shift-click to add an entity or take it out. A plain
  drag still pans. Properties splits the area's nets into boundary nets (the block's interface) and
  internal nets, and lists its parts by class, its findings and its datasheet coverage. Three Ask rows
  bind the whole set at once: what the block connects to, which of its nets have no test point, and
  its parts by class.
- **A live page contract for the viewer** (PR 1158, #1150 to #1152). A page on the viewer's own origin,
  or one `agni serve --embed-origin` names, moves an open viewer over postMessage without reloading
  it (`ViewerPageService` in `protos/agni/v1/viewer/page.proto`) and reads back where it landed.
  `make exercise-viewer-page` drives it. A verdict now carries the sheets its subjects are drawn on
  (`Verdict.sheets`), so a link to a passing verdict opens the sheet that draws it.
- **Links as page calls** (PR 1168, #1153, #1155, #1156). `ApplyLocation` takes any link the server
  mints. A saved check report's links move a viewer already open in the `agni-viewer` window instead of
  loading it again, and an MCP answer carries the page call beside each link.
- **Query witnesses** (PR 1164). `agni query --witnesses` and `RunQueryRequest.witnesses` record, per
  row, the fact or rule behind each goal literal, so a row from a library member shows the rules that
  produced it. The viewer's query panel draws the tree when a reader opens a row. Off by default, and a
  query without it does the same work as before.
- **A declared pull-up reach per net** (PR 1163, #820). `intent: nets: {SDA: {pull_up_reach_hops: 4}}`
  moves the series-resistor limit every pull-up walk uses for that net. A passing `i2c-pull-up`
  verdict now lists every pull-up path, not only the first one found (#821).
- **A per-domain supply binds to its own pin** (PR 1162, #1160). `ident.PinName` folds KiCad's
  subscript markup (`VCC_{A}`) and a pin table's `VCC(A)` to one key, so a dual-supply part's spec
  judges each supply against its own range.
- **A course chapter on design for test** (PR 1161, #777), `learn/13-design-for-test`.
- **The Python client recovers an evicted or stale snapshot** (PR 1159, #1067) by ingesting again
  and asking once more, and `tables_to_xlsx` sizes each column to its contents.

## Fixed

- **A KiCad board read honours a pad's no-connect flag** (PR 1162, #1023), and KiCad DRC items on an
  arc track or an NPTH pad now join to their net or part.
- **Naming one sheet of a KiCad design says so** (PR 1162). The read still happens as named, with a
  note pointing at the design's entry.
- **The docsite's own links are checked** (PR 1170, #1169), and two broken ones are fixed.

## Build and release

- The `agnids` arm64 image builds and is smoke-tested on an arm64 runner, rather than under emulation
  (PR 1146).
- CI runs the gate's two halves in parallel and builds agni once for the browser suite (PR 1148,
  #1147). `make hooks` installs an opt-in pre-push hook that runs the browser suite.
