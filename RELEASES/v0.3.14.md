# v0.3.14

v0.3.14 is the first release to attach prebuilt binaries. v0.3.13 added them, but its release job
failed on a smoke-script bug after building them, so nothing was attached. This release fixes the
script and runs the same build and smoke on every pull request. The engine is unchanged from v0.3.13,
whose notes ([RELEASES/v0.3.13.md](v0.3.13.md)) describe the binaries and the `go install` viewer
download.

## Fixed

- **The release binaries are attached** (PR 1231). The smoke checked the viewer bundle with
  `tar -tzf | grep -qx`, and under `pipefail` GNU tar's write error on the pipe `grep -q` closed early
  failed the job. grep now reads the whole listing. The tarballs also no longer carry macOS extended
  attribute headers when built on a Mac.

## Added

- **`make dist-check` in the gate** (PR 1231) builds and smoke-tests the host platform's tarball on
  every pull request, so a packaging break shows before a tag.

## Install

```
go install github.com/panyam/agni/cmd/agni@v0.3.14
```

or download the tarball for your platform below and put `agni` on your PATH. `checksums.txt` covers
every file.
