# v0.11.5

A team whose hardware repo passes 256 MB could not mount it, though each board fit. A team that can use neither GitHub nor an OIDC provider had no way to sign people in one by one. v0.11.5 mounts a repo past the cap lazily, and adds local accounts with a username and password. A link of a board's declared entry now brings its companions, as a push does. It is a patch over v0.11.4. No exported Go API and no proto field changes shape.

## Added

- **`agni serve --auth tokens --local-accounts` signs people in with a username and password** (PR 1878, issue 1815). `/signin` gains a form, and a good sign-in mints the same agni token a GitHub or OIDC sign-in mints, for `local:<username>`, valid for 30 days. `agni users add|ls|rm|passwd` manages the accounts in `--store`, and only an operator on the server's machine can make one. The store keeps a bcrypt hash. A wrong password and an unknown username get the same 401 and take as long, and the form answers 429 after 5 tries per username or 20 per address in a burst.
- **A GitHub repo past the mount cap mounts lazily** (PR 1881, issue 1877). The server lists the commit's tree and downloads nothing, and a read fetches the folder the file sits in, since a schematic opens its sheets from beside it. A commit under the cap is snapshotted whole, as before. `--mount-max-bytes` and `--mount-max-files` set the cap, as `mount: {max_bytes, max_files}` in `--config` and the chart, and a too-large error names them.
- **`make exercise-formats` runs every format's oracle and prints one row per format and corpus file** (PR 1874, issue 1714). It shows what read, what was compared and a verdict, gives a row to each format with no oracle, and exits 1 while any row fails or does not read.

## Fixed

- **Linking the entry a `design.yaml` declares links its companions too** (PR 1876, issue 1873). Each companion is linked from the same mount and ref as an artifact of its own, with the id `designs push` gives it. A bootstrap `link:` needs only the entry, and a companion added to `design.yaml` arrives on the next sync. A link of a folder whose `design.yaml` names an entry links that entry, where it used to be refused for holding `design.yaml`. A companion is skipped when the design already holds an artifact of its id or one linked to its path.
- **User-facing strings lost their last em-dashes** (PRs 1874 and 1882, issues 766 and 1875). A datasheet-backed rule message ends with ", per <citation>" now. `import-results` writes a KiCad violation and its item as `<violation> (item: <item>)`, and still reads results imported in the old form.
- **`web/src/highlights.ts` held NUL bytes** (PR 1874, issue 360). A `nul-check` in `testall-scan` now fails on any tracked text file holding one.

## Changed

- **goapplib moves to v0.7.37** (PRs 1881 and 1885). It brings lazy GitHub snapshots, credentials looked up only when a mount's driver fetches, and goapplib's two CodeQL fixes. oneauth moves to v0.3.22.

## Upgrading

A script that parses a datasheet-backed rule message by its em-dash should read ", per " instead.
