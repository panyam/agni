# v0.6.16

v0.6.16 marks where a walk starts by the pins it leaves through, rather than with a box around the start part. It also drops the docsite's About the demo page, so the Demo link opens the demo itself. It is a patch. No API changes.

## Changed

- **A walk from a part marks the pins its first hop leaves by** (PR 1575). The part used to get a box drawn around it, though the walk's path already starts at those pins. A walk that starts on a pin keeps its dot. A part whose first hop draws no net keeps the box, so the start still shows. Zooming to the start uses the same marks.

## Docs

- **The docsite's Demo link opens the demo** (PR 1574, issue 1573). The About the demo page is gone. It ended on two of the SVG renderer's test goldens, which looked nothing like the viewer. The server guide now says what the demo holds, that you can drop your own files on its "Open files" page, and that an agent can't move a demo tab. Old links to `/agni/demos/` now return 404.
