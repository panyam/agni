# v0.6.18

v0.6.18 makes a part clicked in a walk open a sheet that draws it. It also adds a third demo video, which follows a signal outwards from a part on Jetson. It is a patch. No API changes.

## Fixed

- **A part clicked in a walk's net row opens a sheet that draws it** (PR 1581, issue 1580). The Trace tab used to locate a part on the first sheet of the net it was listed under. On Jetson, J16.3 sits under the I2C data net, which SoM_IO draws first, so the schematic stayed on SoM_IO though J16 is drawn on Peripherals. The viewer now asks the engine where the part is drawn. It keeps the sheet on screen when that sheet draws the part.

## Docs

- **A walkthrough of a walk** (PR 1579, issue 1578). `make demo-video JOURNEY=walk-a-signal` records a walk from R361, a pull-up on Jetson's I2C connector data line. It walks one hop through small parts, goes one hop wider across the level shifter U80 to the 1.8 V side, and asks for the route to the rail. The README and the docsite's front page play it beside the other two, and the gate plays the journey on the cut.
