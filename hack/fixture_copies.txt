# Files that are meant to be byte-identical copies of each other, one group per block.
#
# hack/fixture_copies_check.sh asserts every group here still matches, AND that no copy exists in the
# tree that this file does not declare. Seed a new group with `--dump`, which prints the tree's copy
# groups to stdout; it never writes this file, because the reasons below are hand-written and a
# regenerate would delete them.
#
# Give every group a reason. The reason is what a later reader needs in order to decide whether the
# copy should still exist, and writing one is the point at which somebody notices it should not.
#
# Nothing here argues that a copy is GOOD. Twenty-four groups is a lot, and the honest reading is
# that this repo duplicates fixtures as a habit. What the file buys is that the next divergence is a
# red gate rather than something found by reading two capture specs side by side (agni issue 509).
